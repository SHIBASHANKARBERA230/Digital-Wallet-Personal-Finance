# Digital Wallet – Personal Finance

A web-based Digital Wallet and Personal Finance Management System developed using Java, Jakarta Servlet, JSP, MySQL, and Maven.

## Project Overview

The Digital Wallet – Personal Finance system helps users manage their digital wallet and personal financial activities through a web-based application.

The project includes user authentication, wallet management, transactions, expenses, budgeting, goals, notifications, and other financial management features.

## Technologies Used

- Java
- Jakarta Servlet
- JSP
- MySQL
- Maven
- HTML
- CSS
- JavaScript
- Google OAuth 2.0
- GitHub OAuth
